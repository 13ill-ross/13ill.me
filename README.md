# 13ill.me

Personal blog built using [Jekyll](https://jekyllrb.com)

[![AI:R READ](https://img.shields.io/badge/AI-READ-grey?style=flat&logoSize=auto&labelColor=13171f)](https://0rwx.com)

## Development

- Install Ruby 3.x using [rbenv](https://github.com/rbenv/rbenv)
- Follow the installation instructions in the [Jekyll docs](https://jekyllrb.com/docs/)
- Install the dependencies using `bundle install`
- Start the server using `bundle exec jekyll serve`

## Scripts

- Get album art covers from Spotify API: `ruby scripts/fetch_spotify_albums.rb src/_data/vinyls.yml`
